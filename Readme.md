# E-Commerce Customer & Sales Analytics Platform

## About the Project
This project analyzes approximately 100K e-commerce orders to uncover insights into sales performance, customer behavior, product performance, delivery efficiency, and customer satisfaction. It uses Python, SQL, MySQL, and Power BI to transform raw data into meaningful business insights.

## Tools and Technologies
- **Programming:** Python
- **Libraries:** Pandas
- **Database:** MySQL
- **Querying:** SQL
- **Visualization:** Power BI
- **Concepts:** Exploratory Data Analysis (EDA), Customer Segmentation, KPI Analysis, Business Intelligence

## Project Objectives
- Analyze revenue trends and sales performance.
- Understand customer purchasing behavior and repeat-customer patterns.
- Evaluate product and category performance.
- Analyze delivery efficiency and its impact on customer satisfaction.
- Build interactive dashboards to support data-driven decision-making.

## Key Features

### 1. Data Analysis Using Python
- Cleaned and analyzed e-commerce transactional data.
- Explored sales trends, customer behavior, and product performance.
- Examined delivery patterns and customer review scores.

### 2. SQL Analysis Using MySQL
- Designed a relational MySQL database.
- Developed 20+ SQL analyses using JOINs, CTEs, subqueries, CASE statements, and window functions.
- Used functions such as `LAG()` and `DENSE_RANK()` to analyze trends and rank product performance.

### 3. Interactive Power BI Dashboard
Developed a 4-page interactive dashboard covering:
- **Executive Overview:** Key business KPIs and revenue performance.
- **Customer Analytics:** Customer purchasing patterns and repeat-customer analysis.
- **Product Performance:** Product and category-level performance.
- **Operations & Customer Experience:** Delivery efficiency and customer satisfaction.

The dashboard includes interactive slicers and page navigation for exploring business performance from different perspectives.

## Key Insights
- **Repeat-Customer Rate:** 3.12% of customers made repeat purchases.
- **Delivery and Customer Satisfaction:** Late-delivered orders had an average review score of 2.57, compared with 4.29 for on-time deliveries.
- **Business Implication:** The difference in review scores highlights a strong association between delivery performance and customer satisfaction, emphasizing the importance of timely order fulfillment.
